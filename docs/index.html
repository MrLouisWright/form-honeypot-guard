Build-time security

form-honeypot-guard

Block form spam bots without a captcha.

$npm i form-honeypot-guard

What it checks

  • Honeypot field filledhoneypot
  • Token missing / bad HMACtoken-missing, token-invalid
  • Token younger than minTimetoo-fast
  • Token older than maxAgetoken-expired
  • Nonce already usedtoken-replayed
  • JS proof missingjs-missing
  • No keypress/pointer/focusno-interaction, signals-missing
  • Content heuristicscontent-*

Quick usage

CLI

npx form-honeypot-guard check [dir]     audit built HTML forms (default: dist)
npx form-honeypot-guard secret [--env]  print a new HMAC secret

Every option is documented in the form-honeypot-guard docs.
