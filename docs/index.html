form-honeypot-guard

Block form spam bots without a captcha.

Layers cheap checks that most bots fail and real people never notice: an accessible honeypot, an HMAC-signed timing token, a JS proof, interaction signals, content heuristics, rate limiting and optional Altcha-style proof-of-work. webpack and Vite plugins, a <2 kB client, and server helpers for Express, Fastify, Next.js, SvelteKit, Remix, Astro and any Fetch runtime.

$ npm i form-honeypot-guard
Read the docs View on npm Source on GitHub

01 The problem

Captchas cost you conversions and accessibility, and most contact-form spam comes from dumb, untargeted bots that a few invisible checks would stop.

form-honeypot-guard adds those checks at build time and verifies them on the server: bots that fill every field, submit instantly, skip JavaScript, replay tokens or flood you get rejected, and people never see a puzzle.

02 Features

01

Accessible honeypot

Off-screen, aria-hidden, tabindex="-1" and autocomplete="off", with a randomised, realistic name per build.

02

Signed timing tokens

HMAC-SHA256 tokens reject submissions that are too fast, expired, tampered with or replayed.

03

JS proof & signals

A proof only a real browser writes, plus keypress, pointer and focus counts.

04

Rate limiting

Sliding window per IP, email or fingerprint, with a correct 429 and Retry-After.

05

Optional proof-of-work

Altcha-style, privacy-friendly PoW with no captcha vendor.

06

Build-time plugins

webpack 5 and Vite plugins add the markup to built HTML and inject the ~1.3 kB gzipped runtime.

07

Framework helpers

Express, Fastify, Next.js, SvelteKit, Remix, Astro, Web Fetch runtimes, and a React wrapper.

08

Distributed stores

Bring your own Redis, Upstash, Cloudflare KV or Durable Object client. Nothing bundled.

03 Usage

# Generate an HMAC secret

$ npx form-honeypot-guard secret

# Audit built HTML forms

$ npx form-honeypot-guard check dist

# Strict audit (warnings fail)

$ npx form-honeypot-guard check dist --strict

# JSON output

$ npx form-honeypot-guard check dist --json

Protect an Express route

import express from 'express';
import { expressGuard, cleanFields } from 'form-honeypot-guard';

const app = express();
app.use(express.urlencoded({ extended: false }));
app.use(expressGuard({ manifest: 'server/form-guard.manifest.json', paths: ['/contact'] }));
app.post('/contact', (req, res) => {
  sendEmail(cleanFields(req.body, { manifest: 'server/form-guard.manifest.json' }));
  res.redirect('/thanks');
});

04 Audit forms in CI

# .github/workflows/forms.yml
name: Forms
on: [push, pull_request]
jobs:
  forms:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - run: npm ci && npm run build
      # exit 1 if a built form is missing protection
      - run: npx form-honeypot-guard check dist
